# Example: Spec-Driven Plan Generation

```markdown
# Milestone 1: API Security & Resilience

## Phase 1: Rate Limiting & Quota Management
- [ ] Task 1.1: Implement Token Bucket Rate Limiter in `backend/security/rate_limit.py`.
- [ ] Task 1.2: Integrate FastAPI Dependency Middleware in `backend/api/deps.py`.
```
